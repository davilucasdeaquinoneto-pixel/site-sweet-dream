# Sweet Dreams — Protótipo de Confeitaria Artesanal

Protótipo web institucional desenvolvido para a atividade acadêmica de criação e apresentação de empresa.

## 🎨 Logotipo & Identidade Visual
- **Logotipo Oficial Incluído**: `logo.png` (Emblema circular rosa e dourado com coroa e cupcake).
- **Cores Pastéis Utilizadas**:
  - Rosa Pastel: `#F8C8DC`
  - Amarelo Pastel / Dourado: `#FDE8B3` / `#D4AF37`
  - Azul Pastel: `#C1E1DC`
  - Lilás Pastel: `#E3C9E6`

## 📋 Tópicos da Atividade Atendidos
1. **Nome e Identidade da empresa** (Sweet Dreams + Logo Oficial + paleta pastel)
2. **O que fazemos?** (Doces artesanais, bolos e solução de problemas de celebração)
3. **Nosso público** (Organizadores de eventos, presenteadores e consumidores finais)
4. **Nossa equipe** (Produção, Design e Gestão)
5. **Nossa diferenciais** (Estética pastel e dourada, sabor equilibrado e embalagens)
6. **Nossos valores** (Afeto, Qualidade e Criatividade)
7. **Nossa meta** (Consolidação em 2 anos e fases de expansão)

## 🚀 Como Rodar
- **Direto**: Abra o arquivo `index.html` em qualquer navegador.
- **Node.js**:
  ```bash
  npm install
  npm start
  ```
  Acesse `http://localhost:3000`.
